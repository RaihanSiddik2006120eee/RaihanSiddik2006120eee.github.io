# Md. Raihan Siddik — Academic Portfolio

Responsive static portfolio for GitHub Pages. No build step or dependency installation is needed.

## Preview

Open `index.html` in a browser, or run `python -m http.server 8000` in this folder and open http://localhost:8000.

## Publish to the existing GitHub Pages repository

Upload the contents of this folder (not its enclosing folder) into the root of `RaihanSiddik2006120eee/RaihanSiddik2006120eee.github.io`, replacing matching files. Keep unrelated repository files. Commit to the branch used by GitHub Pages. If the existing Pages configuration serves that branch's root, the site updates after its deployment completes.

## Accessibility and performance

Keyboard navigation, a skip link, focus indicators, Escape-to-close mobile navigation, reduced-motion support, project-filter announcements and persistent light/dark theme are included. Content is readable without JavaScript; JavaScript adds interactions and reveal animation. Canvas animation pauses when offscreen or the tab is hidden. Fonts use Google Fonts when available and local fallbacks otherwise. No analytics or contact-form backend is included; contact uses email.
